# React Form App with Particle Background

This is a single-page React application that displays a contact form with an animated particle background. It includes:

- Beautiful interactive background built with `tsParticles`
- Tailwind CSS styling
- A secure 16-digit PIN input field formatted as `XXXX-XXXX-XXXX-XXXX`
- Full client-side validation
- React form state management

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the app locally

```bash
npm run dev
```

This will launch the app on `http://localhost:5173`.

## 🛠 Built With

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [tsParticles](https://particles.js.org/)
